# 👋 أهلاً، أنا مجتبى البشراوي

طالب حاسب وآلي ومطوّر برمجيات، أحب الحلول التقنية والابتكار. أجمع بين البرمجة والتصميم وتجربة المستخدم عشان أبني تجارب رقمية مميزة.

[![الموقع](https://img.shields.io/badge/Website-albashrawi.github.io-3D8BFF?style=for-the-badge)](https://albashrawi.github.io)

## 🌐 وش فيه الموقع؟

| القسم | وصفه |
|---|---|
| **عني ومسيرتي** | من أنا، وخط زمني لمسيرتي من أول محاولة برمجة إلى اليوم |
| **أعمالي** | ثلاثة مواقع: GAT Tracker (بإصداراته الخمسة وقصته)، وقدراتي اللفظي، ومنصة التناظر اللفظي |
| **وقت فراغي** | الألعاب اللي ألعبها، والمسلسلات والأفلام والأنميات اللي أتابعها |

## 🛠️ التقنيات

- الموقع نفسه: **HTML5 · CSS3 · JavaScript** صافي، بدون مكتبات ولا إطار عمل
- المشاريع: **Tailwind CSS · Chart.js · localStorage**
- الاستضافة: **GitHub Pages**

## 📁 هيكل المستودع

```
index.html        الصفحة الرئيسية
leisure.html      وقت فراغي
projects/         صفحات مشاريعي
assets/           الصور (بانر ومعاينة الروابط)
```
